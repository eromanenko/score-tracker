# Backlog: Score Tracker v3.0.0

Цей документ містить ідеї та технічне бачення для майбутніх оновлень застосунку Score Tracker.

## 1. Фотографії коробок ігор (Box Covers) замість емодзі
**Опис:** Замінити текстові емодзі на головному екрані на красиві фотографії коробок настільних ігор для більш професійного та привабливого вигляду.
**Технічне бачення:**
- Додати поле `coverUrl` для кожної гри у файлі `assets/games.json` (наприклад, `./assets/covers/hadara.jpg`).
- Створити нову директорію `assets/covers/` та завантажити туди оптимізовані зображення коробок (формат WebP або стиснений JPEG) для існуючих 13 ігор.
- Оновити компонент `game-select.js`:
  - Змінити дизайн карток ігор на сітку (grid) або masonry layout, де більшу частину площі займає зображення коробки.
  - Додати fall-back на емодзі/текст, якщо зображення відсутнє.

## 2. Сортування ігор перетягуванням (Drag and Drop)
**Опис:** Додати можливість користувачам самостійно змінювати порядок відображення ігор у списку на головному екрані.
**Технічне бачення:**
- Використати HTML5 Drag and Drop API для списку ігор у компоненті `game-select.js`.
- Додати непомітну іконку "ручки" (drag handle) або дозволити перетягувати за саму картку.
- Зберігати налаштований користувачем порядок ігор (масив ID ігор) у `localStorage` (наприклад, `custom_game_order`).
- При рендері списку ігор спочатку сортувати масив ігор відповідно до збереженого порядку з `localStorage`, а вже потім виводити нові ігри, які ще не були відсортовані користувачем.
